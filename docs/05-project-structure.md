## قرارات تقنية مهمة اتُّخذت في هذه المرحلة

### 1) نظام اللغتين من أول يوم
- لا يوجد نص مكتوب مباشرة داخل المكوّنات — كل النصوص من `locales/{ar,en}.json`.
- `<html lang dir>` يُحدَّث تلقائيًا عند تغيير اللغة، وكذلك `<title>`.
- اللغة محفوظة في `localStorage` بمفتاح `edulink.language`، والافتراضي **العربي**.
- إضافة لغة جديدة = ملف JSON جديد + إضافتها في `supportedLanguages`.

### 2) المظهر (فاتح/غامق)
- يُطبَّق على `<html data-theme>`، ومحفوظ في `localStorage` بمفتاح `edulink.theme`.
- الافتراضي يتبع إعداد نظام التشغيل (`prefers-color-scheme`).
- سكربت صغير في `index.html` يطبّق المظهر **قبل أول رسم** لمنع وميض الثيم الخاطئ.
- كل الألوان مركزية في `src/styles/tokens.css` — لا ألوان مكتوبة داخل المكوّنات.

### 3) الاتجاه (RTL/LTR)
- استُخدمت **الخصائص المنطقية** (`padding-inline`, `inset-inline-start`, `border-inline-start`) في كل مكان، فانعكاس الاتجاه تلقائي بدون CSS مكرر.
- اتجاه تظليل الصورة يتم عبر متغيّر `--scrim-angle` يُضبط حسب `html[dir]`.

### 4) التجاوب والمقياس (`--u`) — قرار مهم

المقاس `--u` **ثابت** (`1px` = مقاسات الريفيرنس) ولا يعتمد على أبعاد الشاشة إطلاقًا:

```css
:root { --u: 1px; }
```

**لماذا ثابت؟** لأن أي اعتماد على `vh`/`vw` يجعل **الزووم يبدو معطّلًا**: المتصفح يقلّل الـ viewport بنفس نسبة الزووم، فيتقلّص التصميم معه ويتلاشى أثر الزووم تمامًا — وهذه مشكلة واجهتنا فعليًا وطُلِب إصلاحها. المقياس الثابت يجعل الزووم يعمل طبيعيًا.

**التجاوب يتم بـ media queries، لا بتصغير كل شيء بنسبة الشاشة:**

| البُعد | القاعدة |
|---|---|
| العرض ≤ 1180px | يُقلَّص حشو لوحة الفورم أفقيًا |
| العرض ≤ 980px | **تُخفى لوحة العرض** ويأخذ الفورم العرض كاملًا |
| العرض ≤ 520px | يُقلَّص حشو الكارت واستدارته والحشو الأفقي |
| الارتفاع ≤ 860 / 800 / 760 / 720px | يُقلَّص حشو لوحة الفورم رأسيًا تدريجيًا (28 → 20 → 14 → 8) حتى يبقى الكارت داخل الشاشة |
| الارتفاع ≤ 800px | تُضغط مسافات لوحة العرض |
| الارتفاع ≤ 620px | تُخفى لوحة العرض (جوال بالوضع الأفقي) |

**القاعدة عند إضافة أي عنصر جديد للكارت:** اكتب مقاسه `calc(N * var(--u))` حفاظًا على التناسق، وتأكد أن **مجموع ارتفاع الكارت + حشو اللوحة يدخل في 768px** وإلا ظهر تمرير على اللابتوبات.

**لا تمرير عند زووم 100%:** ارتفاع الكارت **712px**، ويدخل بلا تمرير من **1366×768** حتى **1920×1080**، وكذلك على الجوال **390×844** (مُتحقَّق منه بـ 9 مقاسات). والصفحة **لا تُقفل التمرير** (`min-height: 100dvh` بلا `overflow: hidden`) حتى يصل المستخدم لكل المحتوى لو كبّر الخط أو صغرت الشاشة.

### 5) منع زووم iOS التلقائي عند الكتابة

iOS Safari يعمل **زووم تلقائي للصفحة** عند تركيز حقل إدخال خطّه **أقل من 16px**. لذلك:

```css
.input { font-size: max(16px, calc(16 * var(--u))); }
```

الحد الأدنى 16px مضمون دائمًا حتى لو تغيّر `--u` لاحقًا. وأُضيف `-webkit-text-size-adjust: 100%` على `body` لمنع تكبير النص التلقائي. و**لم** نستخدم `maximum-scale=1` لأنها تمنع المستخدم من الزووم اليدوي وتضرّ بإمكانية الوصول.

### 6) الصورة واللوحة

- عرض لوحة العرض **52.8%** من عرض الشاشة — نفس تقسيم الريفيرنس (811 من 1536).
- الصورة تملأ اللوحة بـ `object-fit: cover` (كما في الريفيرنس) فلا تظهر فراغات جانبية.
- **قيد هندسي:** نسبة أبعاد لوحة العرض تتبع نسبة الشاشة، فنسبة أبعاد الصورة داخلها تختلف قليلًا عن 3:2 على شاشات أخرى — وهو قيد لا يمكن تجاوزه في تصميم يملأ الشاشة.

### 7) روح المشروع: كل العناصر بيضاوية

| العنصر | الاستدارة |
|---|---|
| الحقول النصية | `--radius-control` = 999px (كبسولة) |
| الأزرار (تسجيل الدخول، Google، أزرار اللغة والمظهر) | 999px |
| رسالة الخطأ | 999px |
| كبسولة الإثبات الاجتماعي | 999px |
| أيقونات المميزات | دائرة كاملة |
| زر إظهار كلمة المرور | دائرة كاملة |
| **مربع الاختيار «تذكّرني»** | **دائرة مخصّصة** بـ `appearance: none` وعلامة صح مرسومة بـ CSS |
| الكارت | `calc(64 * var(--u))` — استدارة كبيرة |

### 8) الشعار الرسمي

- **الأصول:** `logo-mark.png` (القبعة + حرف e) و`logo-wordmark.png` (الاسم) — مقصوصة من ملف صاحب المشروع عبر قناة الألفا (الملف كان PNG شفاف أصلًا) في `tmp/extract-logo.ps1`.
- **نسختان من الاسم:** `logo-wordmark.png` للفاتح و`logo-wordmark-light.png` للغامق (الأولى فيها «edu» كحلية تختفي على الخلفية الغامقة) — يُبدَّل بينهما بـ CSS حسب `html[data-theme]`.
- الشعار **مرصوف** (العلامة فوق الاسم)، ويأخذ حجمه من `--mark-w` و`--wordmark-w` مضروبين في `--u`.
- الأصول مضغوطة إلى إجمالي **155KB** (كانت 1.32MB قبل التصغير)، وأيقونة الموقع `public/favicon.png` مولَّدة من العلامة.

### 9) المصادقة غير موصولة
- `src/services/auth.ts` فيه `signIn()` و `signInWithGoogle()` ترميان خطأ `AuthServiceNotConnectedError`.
- الواجهة تعرض رسالة «خدمة تسجيل الدخول غير متصلة بعد» بدل أي نجاح وهمي — لا يوجد auth مزيّف.
