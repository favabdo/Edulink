# توثيق مشروع EduLink

هذا المجلد هو **المصدر الوحيد للحقيقة** للمشروع. أي جلسة عمل جديدة تبدأ من هنا.

## ابدأ من هنا

1. `../AGENTS.md` — قواعد المشروع وذاكرته وهويته.
2. `04-progress-log.md` — **آخر نقطة توقف** والخطوة التالية.

## الوثائق

| الملف | المحتوى |
|---|---|
| `01-requirements.md` | كل المتطلبات والقرارات الوظيفية والنطاق والمستثنى |
| `02-tech-stack.md` | الستاك التقني والتوصيات والأسباب وملاحظات الترخيص والسكيل |
| `03-design-reference.md` | قياسات ريفيرنس صفحة اللوجين والألوان والقرارات التصميمية |
| `04-progress-log.md` | سجل التقدم خطوة بخطوة + أين توقفنا |
| `05-project-structure.md` | بنية الكود والتقنيات المستخدمة فعليًا |
| `06-deployment.md` | النشر على Vercel + تحسينات الأداء + التحقق بعد النشر |
| `07-database.md` | قواعد قاعدة البيانات + الجداول + خطة Supabase→SQL Server |
| `08-backend.md` | الباك اند (ASP.NET Core): التقنية وتدفق الدخول والصفحة الداخلية |
| `09-structure.md` | استراكشر المشروع (monorepo + pages/features + namespaces) |

## المجلدات

| المجلد | المحتوى |
|---|---|
| `reference/` | صور الريفيرنس الأصلية (تصميم صفحة اللوجين والهيرو) |
| `screenshots/` | لقطات التنفيذ الفعلي — إنجليزي/عربي × فاتح/غامق |
| `history/` | النصوص الخام من الجلسات السابقة — مرجع تاريخي، غير محدَّث |

## قاعدة الصيانة

عند أي قرار جديد أو إنجاز خطوة: **حدِّث الوثيقة المناسبة حسب الحالة، وأضِف خطوة في `04-progress-log.md`**.
